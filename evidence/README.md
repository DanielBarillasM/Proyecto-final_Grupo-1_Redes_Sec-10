# Evidencias

- `deployment/cidr-validation.txt`: comprobación local reproducible de capacidad, contención y no solapamiento.
- `deployment/terraform-validate.txt`: salida de validación de Terraform.
- `deployment/terraform-plan.txt`: resumen del plan, sin secretos.
- `connectivity/ping-private.txt`: salida real del ping entre las dos instancias privadas de Ventas.
- `deployment/destroy.txt`: confirmación de destrucción de los recursos temporales.

Las evidencias de AWS sólo deben considerarse completas cuando incluyen identificadores y salidas obtenidas de una ejecución real. No se sustituyen con resultados simulados.
